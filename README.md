# TelegramBot-Reminder

Telegram-бот для создания задач и напоминаний на основе естественного языка.

Бот использует LLM для извлечения структуры задачи из текста пользователя, умеет уточнять недостающие данные, сохраняет задачи в базе данных и отправляет напоминания за 1 минуту до дедлайна.

🎯 Что умеет этот бот?



✨ Основные возможности

\- 🧠 Интеллектуальный парсинг — понимает задачи на естественном языке

\- ❓ Уточняющие вопросы — если информации недостаточно, бот спросит нужные данные

\- ⏰ Авто-напоминания — отправляет уведомления за 1 минуту до дедлайна

\- 🗄️ Надежное хранение — все задачи сохраняются в базе данных MySQL

\- ♻️ Устойчивость — работает после перезапуска, не теряя данные

\- 🔄 Полный CRUD — создание, чтение, обновление, удаление задач



📋 Команды бота

| Команда | Описание | Пример |

|---------|----------|--------|

| `/start` | Начало работы, список команд | `/start` |

| `/new` | Создать новую задачу | `/new` |

| `/tasks` | Список активных задач | `/tasks` |

| `/task <id>` | Показать детали задачи | `/task 5` |

| `/edit <id>` | Редактировать задачу | `/edit 3` |

| `/delete <id>` | Удалить задачу | `/delete 2` |

| `/cancel` | Отменить текущее действие | `/cancel` |



🔄 Логика создания задачи



Пользователь вводит текст задачи

Текст обрабатывается через LLM (parse\_task)

Если:

❌ нет даты → бот спрашивает дату

❌ нет времени → бот спрашивает время

После получения всех данных:

\- задача сохраняется в БД

\- пользователю приходит подтверждение

🚀 Инструкция по запуску проекта



Предварительные требования

\- Python 3.11 или новее

\- MySQL 8.0+

\- Токен Telegram Bot (получите у \[@BotFather](https://t.me/BotFather))

\- API ключ для LLM (OpenAI, Anthropic или локальная модель)



Шаг 1: Подготовка базы данных



mysql -u root -p



\# В MySQL выполните:

CREATE DATABASE reminder\_bot CHARACTER SET utf8mb4 COLLATE utf8mb4\_unicode\_ci;

CREATE USER 'bot\_user'@'localhost' IDENTIFIED BY 'your\_secure\_password';

GRANT ALL PRIVILEGES ON reminder\_bot.\* TO 'bot\_user'@'localhost';

FLUSH PRIVILEGES;

EXIT;



Шаг 2: Установка проекта



\# 1. Клонируйте репозиторий

git clone https://github.com/ваш-username/telegram-reminder-bot.git

cd telegram-reminder-bot



\# 2. Создайте виртуальное окружение (рекомендуется)

python -m venv venv

source venv/bin/activate  # На Windows: venv\\Scripts\\activate



\# 3. Установите зависимости

pip install -r requirements.txt



Шаг 3: Настройка конфигурации



\# 1. Создайте файл конфигурации из шаблона

cp .env.example .env



\# 2. Отредактируйте .env файл в любом текстовом редакторе

\# Добавьте свои реальные значения:

nano .env  # или используйте VSCode, Sublime и т.д.



Содержимое .env файла:



\# === TELEGRAM BOT ===

BOT\_TOKEN=ваш\_настоящий\_токен\_от\_BotFather



\# === DATABASE ===

\# Для PostgreSQL:

DATABASE\_URL=postgresql+asyncpg://bot\_user:your\_secure\_password@localhost/reminder\_bot



\# Или для MySQL:

\# DATABASE\_URL=mysql+aiomysql://bot\_user:your\_secure\_password@localhost/reminder\_bot?charset=utf8mb4



\# === LLM CONFIGURATION ===

LLM\_API\_KEY=ваш\_api\_ключ\_от\_openai\_или\_anthropic

LLM\_MODEL=gpt-3.5-turbo  # или другая модель

LLM\_BASE\_URL=https://api.openai.com/v1



\# === APPLICATION ===

TIMEZONE=Europe/Moscow

LOG\_LEVEL=INFO

Запустите бота

python bot.py
